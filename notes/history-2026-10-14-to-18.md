- **sname.bin DECODED (2026-10-14, FUN_00855140; tool `~/Projects/lp2-tools/snamebin.py`, docstring has the format).**
  - CRLF text: 3 ignored bytes (BOM), then "NN" count, then entries. Map entry = "00", area. Only areas 4/8/11/15 are accepted; PC pre-sets those flags, so no new map slots come via DLC.
  - Part entry = category 1-4 (hd, bd, bk, lg), item 0-69, 7 language names, floats (head 3, body 3, back 12, legs 0). Only the first 1024 bytes are read. Max 72 packages.
  - DLC part = id 180+item → descriptor from table 0x16316a0[id-0x7f] = set 0x2e, variant=item. Item 67 duplicates variant 0x2f (Capcom table bug). Items ≥45 have byte3=4.
  - Files: CustomParts\<pfx>2e<vv>.arc + <pfx>2e<vv><cc>.arc, loaded from the package (FUN_007c5120 → FUN_007c4d80 type 2).
  - Part descriptor u32 = set(lo, |0x20) | colour<<8 | variant<<16 | ?<<24. Part ids are u8 everywhere (256-bit unlock masks at +0x50710/30/50/70, saves); base tables are capped at 0x86/0xad/0x7b/0x7b by immediates.
